#  Arrow Slide Puzzle – Brutalist Edition

A minimal, brain‑teasing puzzle game with a raw Neo‑Brutalist aesthetic. Slide arrows off the board, undo moves, get hints, and watch the game auto‑advance when you win.

![Game Screenshot](screenshot.png) <!-- Add a screenshot if you have one -->

## ✨ Features

- **Unique sliding mechanic** – arrows move until they hit another arrow or leave the board.
- **No dead‑ends** – opposite arrows never share the same row or column (←/→ never together in a row, ↑/↓ never together in a column).
- **Undo** – go back up to 20 moves.
- **Hint** – highlights a random arrow that can move.
- **Auto‑next level** – after a win, the next level loads automatically (2‑second delay).
- **Stuck detection** – if no arrow can move, a red warning appears.
- **Custom cursor** – brutalist mouse pointer with hover effects.
- **Fully responsive** – works on desktop, tablet, and mobile.

## 🎮 How to Play

- Click (or tap) on any arrow to make it slide in its direction.
- Arrows slide until they hit another arrow or fall off the board.
- If an arrow leaves the board, it is removed.
- Clear all arrows to win the level.
- Use **UNDO** to revert the last move.
- Use **HINT** to highlight a movable arrow.
- **RESTART** resets the current level.
- **NEXT** manually advances to the next level.
